# История настройки

Здесь сохранены инструкции отдельных шагов и исправлений, использованные
при сборке стенда. Они описывают промежуточные состояния: зоны b/d, ранние
версии приложения, отдельные ZIP-пакеты и первоначальную настройку Logging.
Относительные пути в этих документах соответствуют их прежнему размещению.

Актуальное развёртывание описано в [deploy.md](../deploy.md),
эксплуатация — в [operations.md](../operations.md),
типовые ошибки — в [troubleshooting.md](../troubleshooting.md).
Исторические patch-файлы не нужно применять к текущей конфигурации.
